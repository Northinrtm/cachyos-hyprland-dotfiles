# Wallpapers

Wallpaper image files are intentionally not committed because their redistribution
license has not been verified.

To reproduce the configured layout, provide your own images at:

- `~/Pictures/wallpapers/wallpaper1.png` for `DP-2`
- `~/Pictures/wallpapers/wallpaper2.png` for `DVI-D-1`

Alternatively, edit `~/.config/hypr/hyprpaper.conf`.
